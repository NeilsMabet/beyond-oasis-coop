# Beyond Oasis Coop — gold title update

Replaces the small gray subtitle with **Coop Version** in gold serif pixel art matching the original logo. The approved design is encoded as 54 native Mega Drive tiles. Only the subtitle area changes on the title screen; gameplay rules are unchanged.

The title pixel comparison, basic gameplay, feature, local regression, hit reaction serialized rollback and native audit fixture suites passed. Earlier gameplay build coverage remains available in reports/coop-6; the full campaign and new internet sessions remain unverified.

The ROM is intended for any compatible Mega Drive / Genesis emulator on any platform with two controller ports. Tested setup: RetroArch 1.22.2 with Genesis Plus GX v1.7.4-coop1 on Windows.

**BeyondOasisCoop.zip:** sources, screenshots, reports, patcher, tested modified core and its complete source, plus optional Windows launcher. **BeyondOasisCoop-patcher.zip:** patcher and patch sources. Supply your own supported original ROM. Neither archive contains a game ROM.
